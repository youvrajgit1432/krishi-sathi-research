# Security Policy

This is a **sanitized public portfolio edition**. All data shipped here is
fictional. No real participant, farmer, interview or consent data is included.

## Secrets
- No production credentials or `.env` files are committed.
- Configuration is environment-driven; see `.env.example`.
- If you find a committed secret, treat it as compromised and report it.

## Reporting
Please report security issues privately rather than filing a public issue with
exploit details.

## Scope
This project is a demo/portfolio edition and is not maintained as a
production service.
